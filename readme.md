# rag-starter

A minimal RAG (Retrieval-Augmented Generation) system built from scratch.

Open source. Building in public.

## Goal

Learn how RAG works under the hood by building a working system — no magic, no black boxes.

## Stack

- **Python 3.11+**
- **FastAPI** — REST API
- **ChromaDB** — vector database
- **sentence-transformers** — embeddings
- **Ollama** — local LLM (llama3 / mistral)
- **Docker** — packaging & deployment
